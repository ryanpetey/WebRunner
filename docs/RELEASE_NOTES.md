# WebRunner 1.0.0

WebRunner 1.0.0 is the free first Chrome Web Store release.

- Manifest V3 package with WebRunner's W+arrow icons.
- Per-origin optional website permissions; no blanket required site access at install time.
- Optional bookmark permission requested only for launcher bookmarks.
- Local workflow storage with no account, developer-operated backend, analytics, advertising, or remote logging.
- One-time explicit Terms of Use / Privacy Policy assent before workflows can be created or run after a material legal-policy update.
- Authorized-use language and an explicit prohibition on using WebRunner to bypass authentication, CAPTCHAs, access controls, rate limits, or other technical restrictions.
- Durable workflow engine that can continue across explicitly authorized sites and browser tabs while ignoring ungranted redirect intermediaries.
- Protected sign-in handoff that requests a real user click when the browser requires one instead of attempting to defeat trusted-user-gesture protections.
- Framework-aware text entry for controls that maintain application state separately from visible DOM values, including ServiceNow Service Portal-style controls.
- Native select, Select2, and multi-select support with live choice loading.
- Run progress, Run from here, Stop, workflow delete, new-workflow Cancel, checkpoints, and Send text / keys.
- User-defined consequential actions remain visible in the saved workflow and are not added automatically.
- Public Terms, Privacy, Security, Support, reviewer notes, and release documentation are maintained in this repository.
