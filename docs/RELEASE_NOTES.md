# WebRunner 1.0 Beta

This is the first Chrome Web Store candidate.

- Store-ready Manifest V3 package with extension icons.
- Per-site optional website permissions; no blanket site access at install time.
- Optional bookmark permission requested only for launcher bookmarks.
- Local-only workflow storage with no account, backend, analytics, advertising, or remote logging.
- Prominent in-product disclosure of local website-content handling.
- DOM-aware element mapping and stable readiness checks.
- Text entry that dispatches framework-friendly edit/commit events.
- Native select, Select2, and multi-select support with live choice loading.
- Collapsed workflow steps, run progress, duplicate step, and Run from here.
- Store screenshots and promotional assets use fictional data only.
