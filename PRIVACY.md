# WebRunner Privacy Policy

Effective date: August 23, 2026

WebRunner is a local-first Chrome extension for creating and replaying user-defined website workflows.

## Information WebRunner handles

When a user maps or runs a workflow on a website they have explicitly authorized, WebRunner may process website content needed for that workflow, including page URLs, field labels, accessibility attributes, dropdown choices, and values the user chooses to save in the workflow. WebRunner also processes the user's interactions with the extension, such as which mapped action to run.

Workflow definitions and saved reusable values are stored locally in Chrome extension storage on the user's device.

## How information is used

WebRunner uses this information only to provide its user-facing purpose: mapping, saving, and replaying the website workflows the user creates.

## Data transmission and sharing

WebRunner has no developer-operated backend, account system, analytics service, advertising SDK, or remote logging endpoint. WebRunner does not transmit page content or saved workflows to the developer or sell user data.

When WebRunner fills or clicks a website, that website may process or transmit the resulting form data according to the website's own behavior and privacy practices. That transmission is between the user's browser and the website the user chose to automate, not a WebRunner service.

## Permissions

WebRunner requests website access one origin at a time and only after the user chooses to authorize that site. Bookmark access is optional and is requested only when the user asks WebRunner to create or update a bookmark launcher.

WebRunner does not request access to browser cookies, browsing history, downloads, clipboard contents, or network interception APIs.

## Retention and deletion

Saved workflows remain in Chrome's local extension storage until the user deletes them, clears extension data, or uninstalls WebRunner. Users can revoke a website's access from WebRunner or Chrome's extension settings.

## Security

WebRunner does not encrypt saved workflow values separately from Chrome's storage. Users should not save passwords, authentication tokens, or other secrets as reusable workflow values.

## Chrome Web Store Limited Use

WebRunner's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. WebRunner uses authorized website and browser data only to provide or improve its user-facing workflow automation features. WebRunner does not use or transfer user data for personalized advertising, retargeting, credit-worthiness, lending, or unrelated profiling, and the developer does not permit humans to read user data except where a user specifically provides information for support or where otherwise allowed by the Chrome Web Store User Data Policy.

## Contact

For support or privacy questions, use the [WebRunner issue tracker](https://github.com/ryanpetey/WebRunner/issues/new). Do not include passwords, authentication tokens, confidential form contents, or other sensitive data in an issue.
